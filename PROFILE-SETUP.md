## 4. Contribuições privadas

Acima do calendário de contribuições:

1. abra **Contribution settings**;
2. habilite **Private contributions**;
3. habilite a visão geral de atividade, caso esteja desativada.

Isso permite mostrar volume de trabalho privado sem revelar repositórios, nomes ou conteúdo.

## 5. Histórico antigo

Não excluir projetos antigos. O histórico demonstra trajetória. Use **Archive this repository** quando um repositório:

- não recebe manutenção;
- representa curso ou exercício concluído;
- possui uma versão mais nova;
- tem nome genérico e não serve mais como portfólio;
- não deve aceitar novas issues ou pull requests.

## 6. Regra de manutenção

Uma vez por mês:

- atualizar a seção **Agora** no README do perfil;
- publicar ou revisar ao menos uma nota no `digitalGarden`;
- conferir links dos seis projetos selecionados;
- revisar quais repositórios merecem continuar fixados;
- arquivar experiências concluídas que não representam mais o trabalho atual.

## 7. Critério editorial

Tudo que aparece na primeira tela do perfil deve responder a uma destas perguntas:

1. Quem é Bruno?
2. Que problemas ele resolve?
3. Como ele pensa?
4. Onde está a prova?
5. Como entrar em contato?

Se um elemento não ajuda a responder nenhuma delas, ele provavelmente não precisa estar em destaque.
