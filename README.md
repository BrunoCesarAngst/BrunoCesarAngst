## Sobre mim

Sou desenvolvedor de software no Rio Grande do Sul, Brasil. Trabalho principalmente na construção e evolução de aplicações web corporativas, conectando experiência de uso, regras de negócio e decisões arquiteturais.

Meu trabalho recente envolve:

- interfaces complexas e editores visuais;
- modelagem e execução de regras de negócio;
- aplicações Vue 3 com TypeScript;
- APIs Java com Quarkus;
- contratos, persistência e integração entre front-end e back-end;
- testes automatizados, documentação técnica e evolução incremental;
- ambientes Linux/WSL, Docker e fluxos Git com múltiplos repositórios.

## Como penso software

- A clareza do domínio vem antes da quantidade de código.
- Decisões importantes precisam ser explícitas e rastreáveis.
- Testes devem proteger comportamento, contratos e integrações reais.
- Arquitetura deve permitir evolução sem transformar cada mudança em uma reescrita.
- Ferramentas são úteis quando reduzem atrito e aumentam a qualidade do raciocínio.
