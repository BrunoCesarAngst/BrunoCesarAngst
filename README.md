# Bruno César Angst

**Desenvolvedor de software · Vue.js / TypeScript · Design Systems · Automação de desenvolvimento com IA**

Trabalho com desenvolvimento de aplicações web, interfaces complexas e ferramentas que tornam o processo de engenharia mais organizado e verificável. Minha experiência combina construção de componentes, modelagem de estados, integração entre sistemas e automação de fluxos de desenvolvimento.

Meu foco é compreender o problema, tornar as decisões técnicas explícitas e implementar soluções que possam ser mantidas e evoluídas.

## Experiência profissional — o que fiz

- **Design System empresarial:** desenvolvi uma biblioteca de componentes de interface e sua estrutura de apoio em Vue.js e TypeScript, tratando padrões visuais, reutilização e estados de interação.
- **Infraestrutura de desenvolvimento assistido por IA:** criei uma camada de trabalho com instruções para agentes, organização de repositórios, documentação, contratos e automações para apoiar atividades de engenharia.
- **Engenharia de interfaces e integração:** trabalhei com problemas de regras de negócio, comportamento de interfaces e fronteiras entre frontend, APIs e dados.

**Limite de propriedade intelectual:** essas experiências aconteceram no contexto de uma empresa. Os produtos e os códigos internos da empresa **não são meus projetos de portfólio público** e não são reproduzidos neste perfil. Os estudos de caso descrevem minha atuação e decisões gerais, sem divulgar material proprietário.
